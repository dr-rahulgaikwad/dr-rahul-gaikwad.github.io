## 📋 About

This is the personal portfolio website of Dr. Rahul Gaikwad, a Staff Resident Solutions Architect at IBM and HashiCorp Ambassador. The website features:

- **Professional Experience**: 15+ years in Cloud, DevOps, AI/ML, and GenAI
- **Research & Publications**: 8 AWS blogs, 10 prescriptive guidance, 15+ code samples
- **Awards & Recognition**: HashiCorp Ambassador, Man of Excellence, Indian Achievers Award
- **Education**: PhD in AIOps, MBA, MCA, 35+ technical certifications
- **Media & Speaking**: 30+ sessions at AWS re:Invent, HashiConf, IIT Bombay

## 🚀 Features

- Responsive single-page design

## 🔧 Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/dr-rahulgaikwad/dr-rahul-gaikwad.github.io.git
   cd dr-rahul-gaikwad.github.io
   ```

2. **Open locally**
   ```bash
   # Simply open index.html in your browser
   open index.html
   
   # Or use a local server
   npx serve
   ```
